# Команды разработки генератора

## Разработка репозитория

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Запустить dev-сервер шаблона |
| `npm run build` | Собрать шаблон приложения |
| `npm test` | Запустить тесты CLI |
| `npm run check` | Проверить синтаксис CLI-файлов |
| `npm run docs:dev` | Запустить документацию |
| `npm run docs:build` | Собрать статическую документацию |
| `npm run docs:preview` | Просмотреть production-сборку документации |
